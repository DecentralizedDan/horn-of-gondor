# Security Policy

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities, credentials, or private deployment
details in a public issue.

Use
[GitHub private vulnerability reporting](https://github.com/DecentralizedDan/horn-of-gondor/security/advisories/new)
to provide a description, affected version, reproduction steps, and potential
impact. If private reporting is unavailable, open a public issue requesting a
private contact method without including sensitive details.

Upload tokens, Cloudflare credentials, private receiver configuration,
database contents, and receiver location information should never be included
in a report unless the private channel specifically requires them.
